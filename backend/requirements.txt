# PlaceUp Career Backend — Python Dependencies

# Version policy (adopted 2026-08-24):
#   * Lower bounds are the versions the stack is known to run on.
#   * Upper bounds cap the next MAJOR release. There is no lockfile here, so
#     without a ceiling every `docker build` silently adopts the newest major of
#     every dependency. That is how pandas 3.x, reportlab 5.x and pytest 9.x
#     arrived in this project unannounced.
#   * Raise a ceiling deliberately, after running the test suite — never by
#     deleting it.
