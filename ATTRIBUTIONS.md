# PlaceUp Career - Third-Party Attributions

## UI Components

- [shadcn/ui](https://ui.shadcn.com/) — 48 pre-built UI primitives. Used under [MIT License](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md).
- [Radix UI](https://www.radix-ui.com/) — Accessible, unstyled UI primitives underlying shadcn/ui.
- [Material UI (MUI)](https://mui.com/) — Component library. Used under [MIT License](https://github.com/mui/material-ui/blob/master/LICENSE).

## Animation & Motion

- [Motion](https://motion.dev/) (formerly Framer Motion) — Animation library for React. Import as `motion/react`.

## Icons & Typography

- [Lucide React](https://lucide.dev/) — Icon library.
- [Google Fonts](https://fonts.google.com/) — Inter and Space Grotesk typefaces. Used under [Open Font License](https://scripts.sil.org/cms/scripts/page.php?site_id=nrsi&id=OFL).

## Routing & State

- [React Router](https://reactrouter.com/) v7 — Client-side routing.

## Build & Styling

- [Vite](https://vitejs.dev/) — Build tool and dev server.
- [Tailwind CSS](https://tailwindcss.com/) v4 — Utility-first CSS framework.
- [tailwind-merge](https://github.com/dcastil/tailwind-merge) — Utility for merging Tailwind classes.
- [tw-animate-css](https://github.com/nicholasgasior/tw-animate-css) — Tailwind animation utilities.
- [class-variance-authority (CVA)](https://cva.style/) — Variant styling for components.

- [Recharts](https://recharts.org/) — Chart library (installed, available for future use).
